# Buckeye Labs

## Installation

```bash
# Core installation - Basic SDK functionality
pip install buckeye-python

# Agent installation - Adds AI capabilities and agent tools
pip install "buckeye-python[agent]"

# Development installation - Includes testing and development tools
pip install "buckeye-python[dev]"

# CLI utilities (if supported)
uv tool install buckeye-python

# From source (latest)
git clone https://github.com/jahidhasanlinix/buckeye-python.git
pip install -e "buckeye-python[dev]"
```

## Requirements

- Python >= 3.11, < 3.14
- See [PyPI page](https://pypi.org/project/buckeye-python/) for full details
